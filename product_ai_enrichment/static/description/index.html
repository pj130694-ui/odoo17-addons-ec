Enriquecimiento de Productos con IA — Descripciones e Imágenes Automáticas

Genera descripciones de venta profesionales con GPT-4o y busca imágenes reales en Google Images (Serper.dev) — todo automáticamente en Odoo 17. Ideal para catálogos con cientos o miles de productos.

✓ Compatibilidad: Odoo 17.0 Community & Enterprise  |  Requiere API key de OpenAI  |  Autor: PJFlow.io
✨ Funcionalidades principales

🤖 Descripciones con GPT-4o

Genera descripciones de venta profesionales para cada producto usando GPT-4o de OpenAI. Texto optimizado para conversión con características técnicas y beneficios. Costo: ~$0.002 por descripción.

📷 Imágenes desde Google Images

Busca y descarga la imagen más relevante del producto en Google usando Serper.dev (2500 búsquedas gratis). Pixabay como respaldo gratuito si no hay Serper key configurada.

📌 Botón 'Enriquecer con IA'

Botón manual en el formulario de producto para enriquecer individualmente. Útil para productos nuevos o para forzar la actualización de uno específico desde el formulario.

⌛ Cron automático cada 2 horas

Tarea programada que procesa automáticamente los productos sin imagen o sin descripción en background. Configura cuántos productos procesar por ciclo (20-50 recomendado).

⚙️ Configuración en Ajustes

Configura OpenAI, Serper.dev y Pixabay API Keys desde Ajustes → Enriquecimiento IA. Sin tocar código ni archivos de configuración del servidor.

📈 Escala a miles de productos

Procesa catálogos enteros en background. Ideal para tiendas con 500, 1000 o más productos que necesitan contenido profesional generado rápidamente.

🚀 Cómo funciona
1

Configura las APIs

En Ajustes → Enriquecimiento IA ingresa tu OpenAI API Key y Serper.dev Key para búsqueda de imágenes en Google.

2

Enriquece tus productos

Usa el botón 'Enriquecer con IA' en productos individuales, o activa el cron automático para procesar todo el catálogo sin intervención.

3

Catálogo profesional

Cada producto tendrá descripción de venta profesional e imagen real. Tu tienda online lucirá como un catálogo premium.
