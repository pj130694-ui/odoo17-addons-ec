✨ Funcionalidades principales

🖨️ Formato Produbanco oficial

Layout exacto según las especificaciones de cheques Produbanco Ecuador.

🏦 Banco del Pacífico incluido

También incluye el layout oficial para cheques del Banco del Pacífico.

📐 Precisión milimétrica

Campos posicionados con precisión para impresión en cheques físicos reales.

💰 Monto en letras

Conversión automática del monto numérico a letras en español.

🏢 Multi-empresa

Configura el formato para múltiples empresas con diferentes cuentas bancarias.

📄 PDF listo para imprimir

Genera PDF optimizado para impresión directa sin ajustes adicionales.

🚀 Cómo funciona
1

Configura la empresa

Ve a Ajustes → Empresa y configura los datos bancarios de Produbanco.

2

Crea un pago

En Contabilidad crea un pago con cheque como método de pago.

3

Imprime el cheque

Haz clic en 'Imprimir Cheque' — el PDF aparece listo para tu impresora.
