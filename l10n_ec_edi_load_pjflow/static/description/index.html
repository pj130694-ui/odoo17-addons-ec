✨ Funcionalidades principales

📄 Facturación electrónica SRI

Genera, firma y envía facturas, notas de crédito y retenciones al SRI automáticamente.

🔏 Firma digital p12

Gestiona tu certificado de firma electrónica directamente desde Odoo.

📥 Importación de XML

Carga XML de comprobantes recibidos y crea facturas de proveedor automáticamente.

✅ Autorización en tiempo real

Consulta el estado de autorización del SRI y actualiza los documentos.

📊 Reportes ATS

Genera el Anexo Transaccional Simplificado para declaración mensual.

🔄 Reintentos automáticos

Si el SRI no responde, el sistema reintenta la autorización automáticamente.

🚀 Cómo funciona
1

Carga tu certificado p12

Ve a Contabilidad → Configuración → Certificado Electrónico.

2

Configura la empresa

Ingresa RUC, dirección y datos de la empresa para los comprobantes.

3

Emite facturas

Crea facturas normalmente — el envío al SRI ocurre al confirmar.
