Habilita Stripe como proveedor de pago en Odoo para empresas ecuatorianas sin restricciones.

✨ Funcionalidades principales

🌎 Ecuador habilitado

Elimina la restricción de país que impide usar Stripe en Ecuador.

🔧 Sin modificar el core

Funciona como módulo independiente sin alterar archivos base de Odoo.

💳 Tarjetas nacionales e internacionales

Acepta Visa, Mastercard, Amex y más en tu tienda online.

🔄 Compatible con Stripe oficial

Extiende el módulo oficial de Stripe — todas las funciones originales funcionan.

📱 3D Secure

Soporte completo para autenticación 3D Secure requerida por bancos ecuatorianos.

⚡ Instalación en un clic

Solo instala el módulo y Stripe estará disponible para Ecuador.

🚀 Cómo funciona
1

Instala el módulo

Instala 'Stripe Ecuador' desde Odoo Apps.

2

Configura Stripe

Ve a Contabilidad → Proveedores de pago → Stripe e ingresa tus claves API.

3

Listo para cobrar

Stripe ya funciona en Ecuador — tus clientes pagan con tarjeta.
