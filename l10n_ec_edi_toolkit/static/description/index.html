Ecuador EDI Toolkit — Herramientas de Gestión EDI

Herramientas avanzadas para administrar, diagnosticar y corregir documentos electrónicos del SRI en Odoo.

✓ Compatibilidad: Odoo 17.0 Community & Enterprise  |  Ecuador 🇪🇨  |  Autor: PJFlow.io
✨ Funcionalidades principales

🛠️ Herramientas de diagnóstico

Verifica el estado de los documentos EDI y detecta errores de envío al SRI.

🔄 Reenvío masivo

Reenvía múltiples documentos con error al SRI con un solo clic.

📊 Dashboard EDI

Vista centralizada del estado de todos los comprobantes electrónicos.

🔍 Validador XML

Valida la estructura de los XML antes de enviarlos al SRI.

📋 Log detallado

Registro completo de comunicaciones con el SRI para auditoría.

⚡ Integración total

Extiende y complementa el módulo EDI Loader PJFlow.

🚀 Cómo funciona
1

Prerequisito

Requiere l10n_ec_edi_load_pjflow instalado previamente.

2

Accede al Dashboard

Ve a Contabilidad → EDI Ecuador → Dashboard para ver el estado general.

3

Gestiona errores

Selecciona documentos con error y usa Reenviar para corregirlos.
