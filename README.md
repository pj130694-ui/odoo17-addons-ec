# Odoo 17 Custom Addons — Ecuador

Módulos Odoo 17 Community desarrollados por **PJFlow.io** para el mercado ecuatoriano.

## Módulos incluidos

| Módulo | Descripción |
|--------|-------------|
| `validate_ec_sri` | Validación y autocompletado de contactos con SRI/RC Ecuador |
| `payment_binance` | Proveedor de pago Binance Pay |
| `payment_stripe_ec` | Stripe Ecuador (bypass de país) |
| `product_ai_enrichment` | Enriquecimiento de productos con IA |
| `l10n_ec_sri_2026` | Parche SRI NAC-DGERCGC26-00000009 |
| `ec_account_edi_load` | Cargador EDI Ecuador |
| `l10n_ec_edi_toolkit` | Herramientas EDI Ecuador |
| `l10n_ec_pdc_migration` | Migración PDC Odoo 16→17 |
| `produbanco_check_printing` | Impresión de cheques Produbanco |
| `theme_trionica` | Tema web Trionica |

## Compatibilidad

- Odoo: **17.0 Community**
- País: Ecuador 🇪🇨
